# CineLogged - A LetterBoxd Clone

Like Letterboxd, but for both movies and TV shows. A social tracking platform featuring an intuitive, modern UI and a deep media database. <br>

**Our Goal - Combining the social, diary-like feel of Letterbox with a broader database that covers both movies and TV shows (like IMDb), all wrapped in a cleaner, more intuitive UI. Many users frequently express frustration that Letterboxd lacks TV shows (or handles them poorly) and that IMDb lacks a modern, community-driven social aspect. We're building a solution to this.** <br>
